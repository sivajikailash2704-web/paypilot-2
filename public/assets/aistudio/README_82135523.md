# PayPilot AI

A beginner-friendly local prototype for a financial workflow dashboard. It includes:
- FastAPI backend and browser UI
- SQLite storage with sample transactions
- Optional OpenAI Responses API assistant
- Optional PayPal Sandbox create-order and capture endpoints
- PayPal webhook signature verification endpoint

> This is a learning prototype, not a production payment system. Use PayPal Sandbox only. Never enter real card details or real financial credentials.

## Requirements

- Windows 10/11
- Python 3.11 or newer
- VS Code (recommended)

## Run locally on Windows

1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and select the extracted `paypilot-ai` folder.
3. Choose **Terminal → New Terminal**. Make sure the terminal is PowerShell.
4. Run these commands one at a time:

```powershell
py --version
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -m uvicorn backend.main:app --reload
```

If PowerShell blocks activation, run this command in that terminal, then activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Open:
- App: http://127.0.0.1:8000
- API documentation: http://127.0.0.1:8000/docs
- Health check: http://127.0.0.1:8000/api/health

Stop the server with `Ctrl + C`.

## Optional: enable PayPal Sandbox

1. Create a PayPal Developer account and a REST app under **Sandbox**.
2. Copy its Sandbox Client ID and Secret.
3. Open `.env` in the project root and add the values:

```env
PAYPAL_MODE=sandbox
PAYPAL_CLIENT_ID=your_sandbox_client_id
PAYPAL_CLIENT_SECRET=your_sandbox_secret
```

4. Restart the server. Use the PayPal Sandbox button in the app.
5. To capture an approved order, open `/docs`, find `POST /api/paypal/capture-order`, and submit the order ID returned by the create-order endpoint.

Optional webhook verification requires a webhook configured in your PayPal Developer app. Put its webhook ID in `PAYPAL_WEBHOOK_ID`. The verification endpoint is a prototype helper; production webhook handling must also validate event types, prevent replay/duplicate processing, and safely handle retries.

## Optional: enable OpenAI assistant

Add your API key to `.env`:

```env
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4.1-mini
```

Restart the server. If no key is present, the app uses a simple demo response.

## Main API endpoints

- `GET /api/health`
- `GET /api/dashboard`
- `POST /api/transactions`
- `POST /api/paypal/create-order`
- `POST /api/paypal/capture-order`
- `POST /api/paypal/webhook/verify`
- `POST /api/assistant`

## Troubleshooting

- If `py` is not recognized, install Python 3.11+ from python.org and enable **Add Python to PATH**, then restart VS Code.
- If `backend.main` cannot be imported, confirm the terminal is in the outer `paypilot-ai` folder (the folder containing `backend`, `frontend`, and `requirements.txt`).
- If port 8000 is busy, run `python -m uvicorn backend.main:app --reload --port 8001` and open `http://127.0.0.1:8001`.
